# oreos-man.github.io

Personal website of Orion Stylianou, served by GitHub Pages at https://oreos-man.github.io.

- `index.html`: all the content (About, Resume, Portfolio, Contact)
- `css/style.css`: styling; the colours for the dark and light themes are at the top
- `js/main.js`: the tabs and the theme toggle
- `assets/Orion_Stylianou_CV.pdf`: the web version of the CV (no phone number)

To update the CV download, replace `assets/Orion_Stylianou_CV.pdf` with a new build of the web version.
To link the research repository once it is public, follow the comment in the Portfolio section of `index.html`.
